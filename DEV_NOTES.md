# Design decisions

- Independent implementation; no source copied from reference repositories. HDLconv is GPL-3.0-or-later; hdlConvertor is MIT. Reference clones are read-only and excluded from distribution.
- Studied HDLconv core.py, vhdl2vlog.py, ghdl template and tests/run.sh: separate argument parsing, file validation, conversion and diagnostics. No Docker or synthesis backend dependency.
- Studied hdlConvertor processParser, typeDeclarationParser, exprParser, statementParser and hdlAst declarations: use source-located nodes and recursive structural parsing. Its Python visitors/generators live in the separate hdlConvertorAst dependency; do not vendor that dependency.
- Tokenizer preserves source offsets and line numbers. Parser handles balanced parentheses and recursive statements. Expression translation uses operator precedence, never a sequence of global substitutions.
- VHDL names are case insensitive; symbols resolve to declaration spelling. SV reserved names require escaping.
- Ranges store left/right/direction, including nonzero and descending bounds. Unpacked arrays are distinct from packed vectors. Whole array copies always expand to loops; only identical range tuples can share a loop.
- Process edge recognition is deliberately conservative. Signal assignments use nonblocking in clocked processes and blocking in combinational processes; variables always use blocking.
- Unsupported RTL marks conversion incomplete with ERROR diagnostics. The public text API returns a fully commented diagnostic draft; file API/CLI/GUI refuse to save an incomplete target. Legacy text API may retain commented partial output for inspection, with complete=False. Errors must not replace an existing output.
- GUI and CLI call the same converter; no GUI parsing logic. Standard library only in core.
- Release packaging: PyInstaller onefile/windowed prevents creation of any GUI console/taskbar window. Frozen CLI invocations recover inherited stdout/stderr handles or attach to a parent console when possible. Frozen no-argument entry defaults to GUI; source CLI behavior remains unchanged. Custom hook includes only win-x64/Tcl 8 tkdnd, omitting other wheel platforms and link-time .lib. Optional networking/OpenSSL, compression and decimal backends are excluded after isolated EXE regression; do not add features using them without updating build exclusions. No UPX or system Python modification. Third-party notices are embedded and available via --licenses.
- Module/interface identifiers are canonical lowercase, so named maps match across independent conversions. Internal symbols retain declaration spelling; SV keywords are escaped.
- numeric_std arithmetic carries small local (kind, width) metadata. Explicit size casts preserve intermediate vector overflow even inside to_integer. Signed resize shrinking retains the source sign bit; scalar multiplication converts the scalar to vector width. VHDL negative sll/srl shifts reverse direction. Integer mod adjusts remainder sign without same-sign addition overflow.
- Unsupported clocks do not fall through to always_comb. Acyclic single-write signal chains in process(all) without declarations/branches lower to continuous equations. Other combinational read-after-write signals fail closed because blocking assignments change delta-cycle behavior.
- Complete results with advisory warnings are reviewable; --strict blocks those writes too. Incomplete results are never written as success. Batch destination collisions are errors.
- VHDL declaration initialization follows the user's uniform removal policy in prepare.remove_declaration_initializers, shared by both targets and the legacy API. All signal/process-variable declaration values are cleared, without comments, logs or replacement initial blocks. Constants, generic defaults and reset statements remain. Removal intentionally changes designs that depend solely on power-up values; no equivalence claim is made for those designs.
- Process variables remain static to preserve VHDL process lifetime. Automatic function-local initializers become ordered blocking assignments at the start of the function body: they are per-call computation and must not be dropped. The normalization is idempotent and visits package functions and nested declarations.
- Source decoding is centralized in `hdlconvert.encoding`: UTF-8/BOM first, then strict GBK (which includes GB2312). File output defaults to GB2312 and supports explicit GBK/UTF-8 selection in both CLI and GUI.
- Initializer removal produces no output comments or diagnostics. Other unsupported-construct source comments remain diagnostic artifacts, never a successful saved design.
- GUI enables Per-Monitor V2 DPI awareness before creating Tk and derives Tk scaling from the active monitor DPI. Chinese UI uses Microsoft YaHei UI; default geometry is capped at 1320×1050 with a 50-unit vertical screen margin and top placement. This increases usable height on scaled displays.
- Gmail notifications are concise and sent only for important feature completion or observed usage exhaustion. Always persist WORK_STATE.md and WORK_STATUS.md first; mail failure must not block development.
- After local development and EXE packaging, publishing and GitHub upload require explicit user permission. A local checkpoint commit is allowed; never push, tag, or create/update a Release before that approval.
- Reference snapshots: HDLconv 3aeb734bb503a75703fa8b7432caf80e34352ce1; hdlConvertor 03c081a307850dc3c438df36592fc67b1ef6cfc0. Test external examples in build/ only; do not redistribute reference source.
- Version 2 keeps the mature VHDL-to-SystemVerilog generator for its broader VHDL subset. New VHDL-to-Verilog paths map the VHDL structure directly into `hdl.ir`; Verilog and SystemVerilog share one balanced-token parser and target-aware generators. There are no six independent converters.
- The neutral IR stores expressions structurally. Verilog/SV precedence, packed ranges, casts, concatenation, repetition, process scheduling and instance associations are parsed before generation. Generator code must reject missing type/width evidence instead of guessing.
- VHDL component declarations retain ordered port names/directions. Named and positional instance maps use those directions (or a same-file entity) to determine parent net ownership. If VHDL→Verilog lacks the referenced interface, it rejects the mapping instead of guessing `reg`/`wire`. Parent procedural/continuous assignments to child-driven nets are rejected. The legacy SV generator applies the same ownership checks while retaining logic declarations.
- RTL fragments share the normal balanced parsers, expression typing, declaration normalization, driver checks and generators via hdl.fragments. Unknown external identifiers use explicit external type metadata rather than one-bit storage; no external declarations or temporary module/clock are emitted. A temporary neutral process provides ownership context and is removed with balanced tokens. Declaration/cast-helper prefixes stay outside the bare process body. Width-sensitive VHDL expressions require pasted declarations; a simple self increment by a bit literal needs no invented intermediate cast.
- Fragment context is explicit in API/CLI/GUI. Auto treats bare VHDL if/case/for as clocked body and ordinary signal assignments as concurrent. Comb context validates delta-sensitive reads before using blocking assignments. V/SV snippets retain original operators; VHDL reverse fragments need types and complete always scope for blocking scheduling. Ambiguous bare assignments require a source-language choice. Code output contains no inline advisory comments; context/unknown-type guidance stays in diagnostics. Omitted declaration initializers do not participate in external-name discovery.
- Sized hexadecimal literal text is compacted by stripping leading zero digits while retaining its exact bit width, including all-zero values. VHDL declaration zero fill on a static vector emits `N'h0`. The lexer accepts standard `x"..."` and the requested apostrophe hex alias.
- Verilog blocking process assignments become VHDL process variables, seeded from signals and committed at process exit, so reads after writes retain procedural ordering. Nonblocking assignments remain signals. Mixed scheduling and multiple process ownership fail closed.
- Historical InitPolicy/analyze definitions are no longer used by the VHDL conversion entry point. Removed declaration expressions are not evaluated; retained expressions (constant/generic/reset/function body) still use the normal translator.
- GUI version 2 is a single-document Windows 10 style editor. It calls `hdl.api.convert_text`; CLI calls `hdl.api.convert_file`. Syntax highlighting is visual only and never feeds the parser.

- Family interchange preserves explicit always sensitivity instead of upgrading Verilog always to always_ff. Complete single-target always_comb case decoders lower to pure functions called by continuous assignments, retaining time-zero evaluation in Verilog.
- Verilog/SV-input fixed array default initializers lower to per-element initial loops. VHDL-input signal array declaration initializers are removed before lowering under the current policy. Sized zero replications compact only when the complete self-determined width is statically known.
- Packed structs lower to packed vectors with field offsets; moving part-select widths can be proved by affine bound subtraction. VHDL process locals stay process variables, distinct from blocking module-signal seed/commit variables.
- Function return lowering uses a named function-body block and disable in Verilog, preserving early return. Verilog-to-VHDL only lowers disable that exits a complete function body.

- Driver checking tracks source owners, static target regions, record fields and simple complementary boolean generate predicates. Unknown overlap is rejected; no full resolved-net elaboration is attempted. The neutral generator can still conservatively reject some disjoint procedural targets.
- Null ranges cannot become SV abs-width vectors. Static null ranges are rejected; symbolic declaration/interface bounds receive elaboration guards with a deliberately unresolved module only in the invalid branch. This preserves valid parameter override behavior without adding runtime logic.
- Array copies lower positionally using source/destination directions and proved equal extents; only identical range tuples share a loop. Nested dimensions are limited to 1D/2D.
- Simple supplied packages flatten into module declarations for Verilog-2005; imported constants that influence port bounds/generic defaults require non-ANSI declaration ordering. Package-only and complex overload/binding cases remain unsupported.
- Partial formal maps must statically cover a complete vector without gaps or overlap. Segments concatenate in formal declaration order; output concatenations contribute every connected root to net ownership. Generic fill widths use actual associations/defaults and retain parent parameter expressions.
- Unconstrained vector functions specialize by argument bounds and bounds proved from their return expressions. Return width is never guessed from the assignment destination. Complex expressions, varying branch widths and recursion fail closed.
- Scalar parameter/localparam types keep explicit [0:0] bounds in neutral IR, so Verilog overrides cannot widen a typed bit/boolean and change bitwise-not results. Declaration string attributes persist across the Verilog-family parser/IR/generator.

- VHDL context clauses are consumed, never emitted as SystemVerilog imports. Unused missing library/package references are harmless. Supplied work package definitions and std_logic_unsigned remain internal semantic metadata: SV deep-copies and qualifies exported symbols/types/bounds via context.load_package_context; Verilog flattens supplied declarations. Real missing references still fail. Private range bindings prevent a local constant from changing an imported array range; ambiguous exports are rejected atomically.
- Primitive normalization is independent of library/use text. hdlconvert.primitives holds only interface facts verified against Vivado 2025.2 unisim_VCOMP and matching Verilog models, plus AMD UG953/UG974 templates. VHDL positional port order is not assumed to equal Verilog order (notably IBUFDS_GTE4). Normalize to named associations before both generators, render model parameter kinds/widths explicitly, and infer parent net ownership from verified directions. Unknown explicit vendor cells, incompatible components and explicit UNISIM/work name collisions fail closed. No model implementations are copied or required at converter runtime.
- Source comments are token-offset metadata on AST/neutral IR nodes, with separate header/body/closing/branch/case-choice anchors. Both -- and --- markers become // while keeping comment text. Generators insert commas before inline comments. Normalization relocates comments when source containers disappear; string literals are never scanned as comments. Source comment preservation is independent of initializer removal and conversion diagnostics.
